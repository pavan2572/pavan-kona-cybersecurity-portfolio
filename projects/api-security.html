API Security — crAPI & Response Exposure Auditor

A practical API response review workflow with an executable JSON allowlist auditor, recursive field analysis and unit tests.

Tooling and synthetic tests included · local Burp evidence pending

Project overview

This package gives an API tester a repeatable way to compare a captured JSON response against the minimum fields required by an endpoint. The Python auditor extracts nested response paths, supports arrays and allowlist wildcards, and flags unexpected fields and sensitive-looking names.

OWASP crAPIBurp SuitePython 3API response minimization

What is implemented

Response auditorRecursive JSON field-path extraction, endpoint allowlist matching, sensitive-name detection and JSON report output.
Test coverageExact matches, unexpected fields, sensitive names, array paths and malformed allowlists.
Assessment workflowLocal crAPI setup, Burp capture steps, authorization context, remediation and retest guidance.

Run the tool

From the repository root, run the synthetic example. It is intentionally designed to find unexpected demo fields, so exit code 1 is expected.

python projects/crapi-api-security/scripts/api_response_auditor.py projects/crapi-api-security/examples/response.synthetic.json --allowlist projects/crapi-api-security/examples/allowed-fields.txt --output projects/crapi-api-security/reports/demo-audit.json

Run tests:

python -m unittest discover -s projects/crapi-api-security/tests -v

Assessment workflow

  1. Start OWASP crAPI in Docker with its official local setup guide.
  2. Use two test accounts and capture only authorized lab traffic in Burp Proxy.
  3. Identify endpoint-specific required response properties and write an allowlist.
  4. Export sanitized JSON without cookies, bearer tokens or real personal data.
  5. Run the auditor, manually validate exposure and authorization context, then document remediation and retest.

The auditor is a schema-minimization aid; it cannot independently prove an authorization vulnerability or quantify business impact.
