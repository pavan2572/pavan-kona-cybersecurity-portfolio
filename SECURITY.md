# Security Policy

This repository is an educational portfolio. Do not submit credentials, production logs, customer data, or confidential vulnerability details through public issues.

The intentionally vulnerable API is designed to bind to `127.0.0.1` only and uses synthetic records. Do not expose it to a public or shared network. If you identify an issue in the portfolio code, report it privately to the repository owner rather than publishing sensitive details.

Only test systems you own or have explicit written authorization to assess.
