IOC Enrichment
& Detection

An offline intelligence pipeline that validates and normalizes IPs, domains, URLs, and file hashes; scores analyst-provided confidence and indicator freshness; and exports Splunk lookup data and detection searches.

Runnable pipeline · 6 automated tests

Pipeline capabilities

Indicator validation

Supports IPv4/IPv6, domains, HTTP(S) URLs, MD5, SHA-1, and SHA-256 validation and canonicalization.

Deduplication

Combines repeated sightings, retaining sources, ATT&CK IDs, tags, and observation counts.

Confidence & freshness

Uses an explicit as-of date and analyst-supplied confidence input to create a transparent sorting score.

Splunk output

Exports a lookup CSV and example SPL searches for DNS and network IOC matching.

Run enrichment

python src/threatintel.py \
  --iocs data/sample_iocs.csv \
  --events data/sample_events.jsonl \
  --as-of 2026-11-06 \
  --out reports/generated

Outputs: normalized IOC CSV, Splunk lookup CSV, event-match CSV, and analyst summary.

Important limitations

The sample records use documentation IP ranges, .test domains, and synthetic hashes. The pipeline does not perform live reputation lookups, malware analysis, or actor attribution. Confidence and ATT&CK context must be verified against the original source before operational use.
